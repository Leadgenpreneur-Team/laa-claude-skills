# LAA Claude Skills

Claude Code skills for Local Agency Accelerator (LAA) community members — deploying, editing, and split-testing client landing pages.

## Skills

- **deploy-lander-laa** — Deploys a new client landing page (Cloudflare Pages + D1, A/B split testing, conversion tracking).
- **edit-lander-laa** — Makes a targeted edit to a live landing page (phone number, headline, image, form embed, etc.).
- **new-split-test-laa** — Starts a new A/B test round on a live landing page after a winner is promoted.
